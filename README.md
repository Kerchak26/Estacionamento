# 🅿️ Sistema de Estacionamento
 
> Projeto acadêmico de análise e modelagem de um sistema para gerenciamento de estacionamento.
---
 
## 📋 Sobre o Projeto
 
Este projeto tem como objetivo analisar, modelar e documentar um sistema de gerenciamento de estacionamento. O trabalho envolve o levantamento de requisitos, modelagem de processos e elaboração de artefatos de engenharia de software, como diagramas UML, storyboards e protótipos de tela.
 
O sistema contempla o controle de entrada e saída de veículos, gerenciamento de vagas, cálculo de tarifas e emissão de relatórios — atendendo aos atores: **Recepcionista**, **Cliente** e **Administrador**.

## ⚙️ Funcionalidades Modeladas
 
- Registrar entrada do veículo
- Exibir vagas disponíveis
- Mapear vagas em tempo real
- Estacionar veículo
- Calcular valor da estadia
- Realizar pagamento (Pix, crédito, débito e dinheiro)
- Registrar saída do veículo
- Gerenciar vagas (liberar / bloquear)
- Emitir relatório geral
---
 
## 📌 Técnicas de Levantamento de Requisitos Utilizadas
 
- **Observação** — acompanhamento da rotina de trabalho em um estacionamento real
- **Tipagem** — registro e categorização dos requisitos identificados
